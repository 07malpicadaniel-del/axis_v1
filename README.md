# AXIS v1 + Cockpit Aurora v2

Aplicación de escritorio Tauri v2 + React + Tailwind CSS v4 (gestionada con `pnpm`) diseñada para Arch Linux sobre compositores Wayland (**Niri**, **Hyprland**) y hardware **AMD Ryzen 9 / NVIDIA RTX 5060 Ti (16 GB VRAM)**.

## Arranque en Wayland + NVIDIA (`WebKitGTK`)

En Arch Linux con `niri` o `Hyprland` y el driver propietario NVIDIA, WebKitGTK puede presentar artefactos o fallos DMA-BUF al inicializar el webview. Usa el lanzador incluido:

```bash
# Modo desarrollo (Vite + Tauri Rust watch)
./scripts/start-axis-wayland.sh --dev

# Modo binario compilado (tras `pnpm tauri build`)
./scripts/start-axis-wayland.sh --bin
```

El script exporta automáticamente:
- `WEBKIT_DISABLE_DMABUF_RENDERER=1`
- `WEBKIT_DISABLE_COMPOSITING_MODE=1`
- `GDK_BACKEND=wayland,x11`

## Integración con `aurora-daemon`

El módulo **Aurora v2** se comunica por HTTP/WebSocket local contra `aurora-daemon` (por defecto `http://127.0.0.1:8090`, configurable con `AURORA_DAEMON_URL`).

En la barra superior (`CommandCenterBar`), el endpoint `GET /api/v1/health` reporta tanto las métricas 4D/Gatekeeper como el modo efectivo (`real_con_fallback`, `estricto_real`, `simulado_offline`) y el estado en vivo de los 6 subsistemas nativos:
- **BOB LLM (`127.0.0.1:8085`, `slot_id = 0`)**: Inferencia local única en los 16 GB VRAM.
- **Piper TTS CPU**: Locución neuronal en español mexicano en CPU/RAM.
- **Chromium Headless CPU**: Maquetación PDF/PNG con `--headless=new --disable-gpu`.
- **FFmpeg + NVENC**: Ensamblaje vertical 1080x1920 acelerado (`h264_nvenc` / fallback `libx264`).
- **Browser CDP (`127.0.0.1:9222`)**: Hidratación WebSocket Chrome DevTools para SPAs.
- **SMTP TLS (`rustls`)**: Despacho ejecutivo con cabecera LFPDPPP `List-Unsubscribe`.

## Seguridad ACL (Tauri v2)

Los comandos Tauri registrados en `src-tauri/src/main.rs` (incluidos los 10 comandos `aurora_*` de `axis-module-aurora`) cuentan con manifiesto explícito en `src-tauri/build.rs` (`tauri_build::AppManifest`), permisos autogenerados bajo `src-tauri/permissions/autogenerated/` y concesión explícita en `src-tauri/capabilities/default.json`.
